# PC 端 vs 原型 pc.html 差距分析与重排任务

> 生成于 2026-10-26，基于 `prototype/pc.html`（4960 行 / 204 KB / 126 个功能点 id）
> 与 `pc/ui/`（index.html + app.js）的逐项代码比对。**不是印象，是字符串级核对。**

## 一、结论

原型 126 个功能点 id，实际 PC 命中 **29 个**，缺失 **97 个**。
按功能域归纳，**真正影响"能不能用"的缺口是 6 块**（其余是同一功能的子元素 id）。

| # | 功能域 | 原型有 | PC 现状 | 严重度 |
|---|---|---|---|---|
| 1 | **统计分析页** | 完整（区间×类型、KPI、柱状图、明细表、导出） | **完全没有** | 🔴 高 |
| 2 | **管理页（新建/编辑/删除规则任务）** | 四分类导航 + 列表 + 批量选择 + 表单 | 只有只读列表 + 简易表单，无批量选择 | 🔴 高 |
| 3 | **窗口行为** | 固定方式三选一 + 透明度 40~100% + 吸附边缘 + 收起小三角 | 只有「普通窗口」+ 贴壁纸（后端有），**无透明度/无收起** | 🟡 中 |
| 4 | **当天面板** | sheet + 全选/全完成 + 打卡成功 toast + 撒花动效 | 有面板，但无「全部完成」按钮、无打卡反馈动效 | 🟡 中 |
| 5 | **笔记页增强** | 筛选、更多菜单、思维笔记、重命名 | 只有基础编辑 | 🟢 低 |
| 6 | **设置页** | 令牌、测试连接、同步状态、导出、清理 | 有 URL + 同步，缺令牌/测试/导出/清理 | 🟡 中 |

## 三、重排后的 PC 任务（按依赖与影响排序）

### P0 · 补齐原型核心交互（不做则"对不上"）

**T1 · 窗口行为三件套**
- 顶栏加「贴桌面壁纸 / 置顶窗口 / 普通窗口」三选一（后端 `set_wallpaper_pin` 已有，接上即可）
- 透明度滑块 40~100%（需新增 Rust 命令 `set_opacity`，用 `WebviewWindow::set_opacity`）
- 吸附边缘（后端 `snap` 已有，接上）
- 收起为贴边小三角（需新增 Rust 命令 + 前端形态）
- 验收：三项都能真机操作并持久化

**T2 · 统计分析页**
- 时间范围（本周/本月/近30天/全部）× 统计类型（完成率/按规则分组/连续打卡）
- KPI 四宫格 + 柱状图 + 明细表
- **数据由本地 rule + completion 现算**，不写死
- 可复用 Android 的 `StatsEngine` 算法（Rust 重写一份，与 Go/Android 对齐）
- 验收：数字与直接查库一致

**T3 · 管理页补齐**
- 四分类导航（规则/记事/倒数日/笔记本）
- 新建按钮 + 完整编辑表单（含提醒区）
- 批量选择模式（多选 → 批量删除）
- 验收：能从零建一条规则并打卡

### P1 · 体验补齐

**T4 · 当天面板增强**
- 「全部完成」按钮
- 打卡成功 toast + 动效

**T5 · 设置页补齐**
- Bearer Token 输入（后端已支持）
- 测试连接按钮
- 导出（调 `/api/v1/export`）
- 清理数据

### P2 · 次要

**T6 · 笔记页增强**（筛选、更多菜单、思维笔记）

## 四、验收标准（整体）

1. 原型里能点的，PC 里都能点（用 CDP 逐项断言）
2. 原型里显示的，PC 里显示一致（视觉比对脚本已有 51 项，扩到覆盖新功能）
3. `cargo test` 全绿，既有 88 条不回退
4. 每项功能都有真窗口 CDP 证据，不接受"代码写了"

## 五、根本原因（为什么差了这么多）

前几轮我按"功能清单"逐项实现（打卡、提醒、同步、贴壁纸），**但从未拿原型逐屏对照**。
原型的 126 个 id 是一份现成的验收清单，我一直没把它当基线用。

**改正**：以后每轮 PC 改动都要跑一次 id 级比对，把"原型有 / PC 无"的清单打出来。

## 关键交互（截图里看出来的，必须照做）

1. **折叠是点箭头**，不是点整卡——点卡片其他地方是「编辑规则」
2. **右侧开关直接生效**，不用进编辑页
3. **任务行有独立的编辑/删除图标**，不是靠左滑或长按
4. **FAB 固定在右下角**，随当前分类变化新建对应类型
5. **「完成」按钮在右上角**，退出管理页

## 验收标准

- 5 张截图对应的每个界面都能在 PC 里复现
- 每个交互都能点（折叠/开关/编辑/删除/FAB/完成）
- 无假按钮
